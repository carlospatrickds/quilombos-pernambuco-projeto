# Inventário documental — Biblioteca do Atlas Territorial Quilombos de Pernambuco

**Versão:** 1.0  
**Data da conferência:** 27/11/2026  
**Fuso de registro:** Recife (UTC−03:00)  
**Repositório:** https://github.com/carlospatrickds/quilombos-pernambuco-projeto

Este inventário organiza fontes acadêmicas, bases estatísticas, legislação, registros institucionais e referências visuais. Ele distingue o tipo e a finalidade de cada documento. A presença de um registro na Biblioteca não significa que todos os seus dados estejam integralmente validados para publicação.

## Política permanente de fontes e validação

As regras obrigatórias para hierarquia de fontes, distinção entre pessoas, comunidades, localidades e territórios, validação, estados de conferência, base nominal e publicação dos dados estão documentadas em:

- [Política de fontes, validação e publicação de dados quilombolas](POLITICA_DE_FONTES_E_VALIDACAO_DOS_DADOS.md).

Este documento orienta todo o trabalho futuro de coleta e atualização do Atlas. O inventário registra as fontes específicas; a política define como elas devem ser avaliadas e utilizadas.

---

## Critérios de situação

- **Conferido:** identidade bibliográfica e endereço ou arquivo de acesso identificados; escopo de uso definido.
- **Conferência parcial:** fonte identificada, mas páginas, metadados, versão ou conteúdo ainda precisam de revisão.
- **Conferência pendente:** referência indicada, mas o arquivo, endereço ou conteúdo específico ainda não foi recuperado.
- **Fonte dinâmica:** cadastro ou painel institucional sujeito a atualização; registrar data de extração sempre que os dados forem usados.

Cada registro deve preservar: título, autoria, instituição, ano, tipo, resumo, finalidade no Atlas, páginas/tabelas utilizadas, endereço de acesso e situação de conferência.

## 6. Regras de manutenção do inventário

1. Não preencher autoria individual quando a responsabilidade for institucional ou não estiver identificada.
2. Não converter um link de consulta em prova de que todos os dados daquela base foram conferidos.
3. Para bases dinâmicas, guardar arquivo original, filtros, data e procedimento de extração.
4. Registrar páginas, tabelas, quadros e variáveis efetivamente utilizados; se ainda não mapeados, escrever “a indexar”.
5. Diferenciar autodefinição/certificação, processo administrativo, delimitação e titulação.
6. Para imagens, registrar autoria, instituição/acervo, licença ou autorização e restrições; crédito não substitui autorização.
7. Atualizar este documento e o registro correspondente na interface sempre que uma fonte for incorporada, substituída ou reavaliada.
8. Não usar ausência de registro como evidência de inexistência de comunidade.
